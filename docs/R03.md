# Last Impact R03
Lobby 2D independiente, icono vectorial original, selector de calidad, pantalla de operador provisional, diagnóstico 3D y regreso al menú. El modo Battle Royale y armamento de lobby no están activos. En Android se evita el escalado interno y las sombras de la revisión anterior; los materiales del escenario se simplifican. No se confirma que la pantalla negra esté corregida hasta probar el teléfono físico. Si también falla el lobby, registrar logcat de Android; si se ve el menú pero no el cubo naranja, investigar el controlador gráfico. No usar este APK de depuración como versión comercial.
