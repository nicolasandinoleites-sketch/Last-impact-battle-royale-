# R07.1 — Loot and inventory prototype

Based on R07.0 (92a0dc8d51177b791f530c015b0dd3f7809d35e0). Separate training scene retained. Nine fixed supplies (three of each kind) with distinct colored procedural containers and minimap indicators. Manual pickup within 1.8 world units; partial pickup preserves remainder. Inventory caps: three medkits, three shield cells, 180 reserve energy units. Medkit restores up to 35 HP, shield cell up to 25 shield; neither consumed at maximum. Gameplay buttons and desktop F/H/G keys for pickup/heal/shield. Round reset restores items, quantities, and inventory. No persistent inventory or randomized loot yet.

Tests added for distance, duplicate collection, capacity, partial pickup, consumable use, and reset; additional visual capture checkpoints. Tests not confirmed executed. Drones remain provisional; humanoid opponents, full inventory UI and multiplayer remain future work. Original character and weapon unchanged.

APK export remains disabled by default; require automated checks, actual visual inspection and Android device verification before delivery.
