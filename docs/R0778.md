# R07.7.8 experimental FRONTIER descent

Opt-in scene deployment_preview.tscn; normal survival.tscn and lobby retain the previous behavior. Uses actual RAZE and FRONTIER, existing player camera and collision capsule, provisional deployment pose, input and phase HUD. Pauses rivals and zone, suppresses combat and pickups, restores ground control on validated landing, restarts deployment on round reset. Horizontal sweep and collision-aware movement reject unsafe landing. A side contact can temporarily stop descent; near-edge recovery and cinematic visual continuity still require tests.

Aircraft and backpack GLB are not in this repository; no substitute meshes, no cabin cinematic in the preview yet. No Android APK. CI and visual tests required.

## Running the preview

Open the project with Godot 4.6 after importing RAZE and decoding IGNIS. Run deployment_preview.tscn directly (F6), not the production lobby. Press Space or the SALIR / ALAS touch button to advance introduction, exit the virtual aircraft and request glide; use WASD or the touch joystick to steer relative to camera yaw. F2 resets. Escape returns to lobby. Auto-exit and auto-glide also remain available.

Acceptance: the real map and player load; normal combat is unavailable until touchdown; the zone does not shrink in flight; a valid landing restores player physics, weapon visibility and rival physics; reset starts a clean deployment. Standard survival smoke test must still pass. No claims of visual quality or Android performance from these headless tests.
